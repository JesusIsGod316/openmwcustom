## Evidence-backed cause and changes

`captureMaterial` preserved OSG texture units, while `captureGeometry` required a matching Vec2 stream in every slot up to the largest unit, including unbound holes. It also omitted the existing-array fallback implemented by `ShaderVisitor::adjustGeometry` in `components/shader/shadervisitor.cpp`.

`v4effectuv.hpp` captures only bound stages, preserving explicit requested arrays. For absent explicit arrays it follows native selection: UV0, or the first non-null source array when UV0 is absent. Each stage retains its original unit's TexMat. Captured streams and material references are compacted together only after all stages validate. The source OSG drawable is not mutated. Malformed arrays, absent coordinates, and generated-coordinate stages without mesh arrays remain explicit failures; no coordinates are fabricated and no material stages are silently discarded.

Failure provenance now includes the corrected model path, capture identity, original drawable name/type, texture identity/unit, selected source array, element and vertex counts, and TexGen state. This should identify the actual asset if the isolated route still fails; it does not retroactively identify the old reference.

Actor-plan reuse and the actor-rebuild, legacy-water-composition, and procedural-water controls are unchanged. Particle geometry generation is unchanged.

An earlier Clang sanitizer compile attempt timed out; no result is claimed for that attempt.
