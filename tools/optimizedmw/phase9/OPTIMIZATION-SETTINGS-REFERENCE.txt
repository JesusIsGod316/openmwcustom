OPTIMIZATION SETTINGS NAME REFERENCE

Existing configurations keep working. A descriptive key wins over its old
alias in the same file, in either order. Normal configuration-layer precedence
is preserved, including user settings overriding shipped defaults. Saves use
descriptive keys. Unknown settings are not renamed.

The legacy performance profile preserves historical overrides. Set it false
to use the individual controls. The editable OptimizedMW_Optimizations.cfg
does this explicitly and retains the promoted Lua, occlusion and shadow
foundation using their direct controls. RAM retention uses the lower Headroom
profile. Benchmark selections use frozen settings rather than this template.

NEW INDEPENDENT CONTROL
[Cells] generated static lod active grid = false
Set true to allow the selected L1 asset mechanism on certified static members
of the active grid. L1 benchmark selections set it true; the asset control and
H1-only selections set it false. Custom configuration preserves your value.
The L1 asset switch, object paging active grid, paging optimizer, paging
readiness split, active grid prepare mode 1/2 and prepared chunk quality
mode 1/2 are also required. The current benchmark foundation already supplies
these controls. Disabling this setting retains the distant-only L1 path.
Ordinary strong preparation precedes optional L1 cooking; resource denial
keeps that strong control. Collision, picking, shadows and secondary views
retain original geometry. Selection alone does not establish runtime use.

ADDITIONAL INDEPENDENT CONTROLS
[Lua] protected call reuse = false
Startup-only private registry reuse of the zero-upvalue protected-call C
trampoline. Nested jobs remain stack-local; lua_pcall, error propagation,
script initialization and event order remain ordinary. Does not defer timers
or parallelize the shared VM. Measured closure counts establish engagement.
[Optimizations] paged static vertex arrays = false
Ordinary paged static Geometry may use OSG's native vertex-array objects when
its exact immutable arrays, primitive layout and callbacks are certified.
Changed inputs select ordinary fallback. Does not enable indirect drawing,
change culling or remove the dynamic draw barrier.
[Optimizations] owned cell cull snapshots = false
Cell-root-owned direct-child bounds and classification, invalidated by the
same OSG dirty-bound contract as ordinary traversal. Current cull order and
MSOC decisions remain; callbacks that change bounds select live fallback.
Metadata is capped at 4096 children/root and 8 MiB total with safe refusal.
[Optimizations] unchanged transform bounds = false
Only identical finite setter inputs avoid dirtyBound. Real changes, signed
zero assignment, nonfinite inputs and independent child dirtying remain.
[Cells] scene template coalescing = false
Concurrent misses can adopt an already finished template in the same exact
manager/VFS/shader generation. No wait or second decoder. An in-place file
edit still requires the existing explicit reload/invalidation contract.
[Optimizations] temporal history lookup = false
Bounded exact instance index over existing previous motion surfaces. First
compatible match and all material/pose checks remain. Does not enable DLSS,
jitter or dense motion. Requires the separately enabled dynamic producer.
[Cells] preload priority promotion = false
Move an already admitted, still-queued cell job into the near-future lane and
enqueue new near-future jobs there. Preserve existing urgent/front jobs, FIFO
within each lane, the same capacity/owner and four-start background fairness.
No additional workers or changes to a running producer's memory policy.
Queue-start counts prove scheduling engagement, not CPU readiness/adoption.
[Cells] paging score value reuse = false
Requires actual paging vertex-cache optimization work. Reuse exact float
power-function results within a single preparation job. Triangle scoring,
tie order and index output remain the control contract. Large valences keep
ordinary computation. This targets preparation cost, not draw-call count.
[Optimizations] indirect projection proof reuse = false
Requires the indirect pipeline. Reuse the successful full projection-family
proof inside that same draw's held source-reader scope and exact State/Program.
The initial full source/import check and actual consumed projection remain.
[Optimizations] indirect early admission fallback = false
Requires the indirect pipeline. When the existing cached admission sample
refuses new private storage, draw live ordinary geometry before optional proof.
Contended inspections also use the ordinary path without waiting. Existing
owners retain their proof/fence rules; budgets and memory floors are unchanged.

[Cells] lod retain source indices = false
Requires the L1 lane. Share immutable source primitives while cooking;
only actual reduced outputs receive new indices/EBOs. Cache-hit admission
is independent. Control retains the existing deep primitive copy.
[Optimizations] indirect command reuse = false
Requires the opaque indirect or GPU visibility pipeline. Reuse populated
CPU command slots; refill a slot after GPU visibility has changed it.
Existing slot fences, pressure admission and ordinary fallbacks remain.

[Optimizations] indirect context capability reuse = false
Requires the indirect lane. Reuse current-owner version/function metadata;
resolve GPU-only functions only for actual GPU requests. Mutable bindings,
program readiness, pressure admission and fence retirement still apply.
[Optimizations] gpu visibility opportunity filter = false
Requires GPU visibility. Strictly contained immutable bounds use original
primitives without private allocation, dispatch or submission. Partial,
ambiguous and unsupported projections keep the existing GPU/control path.
