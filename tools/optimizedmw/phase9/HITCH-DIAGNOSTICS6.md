# Six diagnostic groups for the switchable hitch trial

The existing four-mechanism trial remains independently selectable in all 16 combinations. Normal and Deep select the same gameplay mechanisms. Normal keeps the frame/pacing series; Deep adds the following observations. This revision does not promote a mechanism or establish a gameplay improvement.

| Group | Observations | Interpretation boundary |
| --- | --- | --- |
| Per-spike work tree | Every relative spike and >=25 ms frame, plus selected positive local deviations, joins to exact engine-wall anchors. Original span IDs, same-thread parents, causal dependencies, overlapping workers and retained residuals are preserved. | Worker overlap is concurrency, not proof it blocked the frame. Origin frame does not assign a later worker's execution to the earlier frame. Engine wall time is not display presentation timing. |
| Preparation to first retrieval | Immutable lifetime tokens attach scene template, NIF, keyframe and prepared-instance publication to explicit optional preparation, first required API retrieval and retirement. Exact cache owner, pointer and VFS generation are retained. | First retrieval is not first visible draw or GPU use. Unclassified speculation and unknown generation/use remain explicit. The registry is bounded to 65,536 lifetimes and never reuses a token. |
| Model construction | NIF graph/geometry, skin, particles, controller targets, skeleton and LOD cleanup; template filters, shaders, optimization, shared state and bounds; clone copy, target remap, pin and particle initialization. | Only executed paths and retained scopes are observed. Parent/child and parallel durations overlap. Counts describe the instrumented conversion/copy path, not an extra scene traversal. |
| Physics and navigation | Immutable physics-cycle ownership, work/batch/barrier/wait/AABB/LOS/commit envelopes; navigation queue admissions, CPU preparation, cache/recast, serialization, database work, tile publication, requeue and cancellation. | Queue time and blocked wait differ from execution time. Existing worker counts, lock order, DB inputs and required behavior remain intact. Full runtime acceptance requires a game capture. |
| Queues and retirement | Immutable per-admission queue receipts, actual execution/completion/cancellation and waits; cache expiry/pressure scans, manager maintenance and final owner release. | A reused WorkItem preserves the admission that first satisfied its original done predicate. Owner release does not prove destruction or returned OS memory. Remaining references and size estimates are observations. |
| Lua allocator and explicit GC | Actual free/realloc service wall time, attempted size-bucket counts, failure/refusal categories, actual explicit GC-step return, requested progress and heap endpoints. | Deltas are inclusive across nested Lua operations. Heap changes do not prove a GC pause. Automatic GC inside arbitrary Lua calls is unavailable without a VM sampler. |

The pinned LuaJIT sampler is deliberately disabled: it has no active-owner query, can replace an existing same-VM profiler, flushes JIT traces when stopped and adds a Windows timer thread. Those effects would change the workload being diagnosed. `lua.gc.observation` records `unavailable_without_vm_sampler`; no automatic GC duration is inferred.

Deep uses the existing pre-touched, bounded recorder. Additional receipts can fill its arena sooner. Capture status, normal completion, output success and dropped rows qualify the raw CPU timeline. `HITCH-DIAGNOSTICS6-CAPTURE.json` separately qualifies lifecycle metadata and reports unknown provenance. Auxiliary incompleteness does not discard an otherwise complete CPU timeline. Zero rows are reported as unobserved paths, not zero cost.

Post-run `HITCH-SPIKE-WORK-TREES.jsonl` references original rows in `HITCH-SPIKE-NODES.csv`. `HITCH-SPIKE-REPORT.json` records exact/partial anchors and bounded-report completeness. Overlap plus ancestry references share a four-million-reference limit. Pacing inputs and selected events are bounded. Regeneration requalifies current raw evidence; missing sources, epoch mismatches and failures remove only the regenerable derived node/tree files. Raw evidence is never deleted by this report.

Frame anchors are synchronization intervals and are excluded from phase work totals. Main-thread coverage is an interval union, not explained cost. A scope crossing a frame boundary cannot have its self time allocated exactly to that frame; it remains visible but is excluded from the ranking of wholly contained residuals. Fast filtered children remain partially unresolved. Proprietary driver internals and unrecorded GPU events remain unavailable.

Run the existing launcher, choose H for the switchable trial, choose the feature combination and then Normal or Deep. Use matching saves, route, asset/settings cohort, frame cap and first-visit/revisit labels. Compare gameplay performance using Normal captures; use matching Deep captures to diagnose the affected intervals. Optional Windows tracing remains a separately started recorder.
