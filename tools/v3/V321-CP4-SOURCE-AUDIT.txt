SHADOW AUDIT AND REPAIR
1. The rejected Mask_PlayerSecondaryView design could not work reliably:
   shadow traversal ANDed its caster mask with SceneCam's starting traversal
   mask, after SceneCam had already removed the secondary bit.
2. Replacing a body-part node mask also removed ordinary traversal semantics.
3. Mode131 now keeps the real animated head, hair and helmet-provided parts on
   their normal player/update masks.
4. Marked parts receive a cull callback that suppresses only Constants::SceneCamera.
5. Shadow, reflection and refraction cameras therefore traverse the live parts.
6. Gameplay intersection exclusion reads the marker separately and covers Node,
   Group, Transform and Geode attachment roots.
7. Mode130 retains CP3's complete-removal path for causal comparison.

PATCH-FREE ANIMATION COMPATIBILITY AUDIT
1. Legacy animation frameworks classify armature type by camera.getMode() and
   discard third-person overrides in Lua before calling the engine.
2. No downstream player or skeleton fix can recover an override that an
   unmodified framework never submitted.
3. The central sandbox loader marks scripts that actually require
   openmw.animation; no mod name, path or version is recognized specially.
4. In Mode131 only, marked animation scripts receive ThirdPerson from
   camera.getMode() during full-body first person. Camera/UI-only scripts keep
   the physical FirstPerson result, limiting compatibility behavior to the
   consumers that need animation perspective.
5. C++ Camera::getMode() remains physical FirstPerson. Lua getPhysicalMode()
   exposes that exact state, isFullBodyFirstPerson() remains the feature query,
   and getAnimationMode() remains the explicit modern animation query.
6. Mode130 keeps getMode()==FirstPerson in every script.
