# V3.4 Occlusion / Shadow Lab

Base: V3.3 checkpoint `eeddad69b7db1d77ef975b7109fbffe69be97fe5`.

## Runtime experiments (all default-off)

- `[Camera] v3.4 broaden occlusion = false`
  - large active-cell objects that did not insert their own occluder proxy may be tested against the completed full MSOC depth buffer;
  - admitted occluders are never tested against themselves;
  - launcher option 15 pairs this with a 250-unit occluder minimum radius, 8192-unit occluder range, and 45000-triangle occluder budget.
- `[Shadows] v3.3 far cascade resolution divisor`
  - V3.4 extends the accepted range to 1..4;
  - divisor 4 makes only the far cascade quarter width/height (1/16 pixels), with near/middle cascades unchanged.
- The proven V3.3 Lua idle-timer fast path remains independently selectable and is included in combined V3.4 options.

## Occlusion cache wiring

`Objects` already retained the persistent `OcclusionStorage*`, but V3.3 did not pass it when constructing `CellOcclusionCallback`. V3.4 passes the existing storage pointer to both cell-root construction sites so unpaged cell occluder meshes can participate in the persistent cache.

## Unified benchmark

`V3_Unified_Test.bat` uses the City-mode route but now captures the superset of Lua/traversal, render, post-FX, MSOC detail, shadow, GPU-memory and OSG timing streams in one OpenMW run. The old City/Render/Transition launchers remain available as specialty/compatibility shortcuts.

Launcher options:

- 15: broadened MSOC only
- 16: aggressive far cascade divisor 4 only
- 17: broadened MSOC + Lua idle-timer fast path
- 18: broadened MSOC + Lua fast path + aggressive far shadow
