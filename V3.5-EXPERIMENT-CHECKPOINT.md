# V3.5 experiment checkpoint

Branch: `v3.5-coarse-occlusion-shadow-cache`

This checkpoint builds on the known-good V3.4 runtime and adds independently selectable, default-off experiments.

## Coarse MSOC

- Tests whole paged-object chunks with a tight precomputed local AABB before traversing the chunk.
- Tests whole groundcover chunks with the existing chunk bounds before traversing their instanced geometry.
- Uses the baseline individual-occluder policy (400 minimum radius, 6144 maximum occluder distance, 30000 triangle budget) instead of V3.4 option 15's more expensive 250/8192/45000 policy.
- Adds separate paged-chunk and groundcover-chunk test/rejection counters to MSOC telemetry.
- Groundcover never becomes an occluder; it is only a coarse occludee.

## Far-shadow experiment

- Retains the proven divisor-4 far cascade (512x512 when the base shadow map is 2048x2048).
- Adds opt-in bounded far-cascade reuse while actor/player shadow settings remain enabled.
- Reuse is safety-clamped to interval 2: a cached far map can be at most one rendered frame old.
- Existing light/camera projected-drift guard remains active.
- This is not yet a static/dynamic shadow-map split; the one-frame bound is intentional until runtime evidence justifies the larger architecture.

## Lua diagnostics

- Adds thresholded first-materialization attribution for `ScriptsContainer::ensureLoaded()`.
- Separates preparation, public-interface/package setup, script sandbox/body execution, init/load handlers, timer restoration, heap setup, and tracker work.
- Does not move the Lua worker barrier and does not change activation ordering or script semantics.

## Benchmark invariants

- Unified benchmark forces `[Groundcover] density = 1.0` for historical comparability and restores the user's original `settings.cfg` afterward.
- New V3.5 experiments are options 19-23 in `V3_Unified_Test.bat`.
